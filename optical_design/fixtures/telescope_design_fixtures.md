# Telescope Design Regression Fixtures

Precomputed, self-checked `(f, D, m, β) → (R1, R2, K1, K2)` cases for the design layer.
Companion to `TELESCOPE_DESIGN_REFERENCE.md`. Generated by `make_fixtures.py`; machine
-readable copy in `telescope_design_fixtures.json`.

**Convention (Schroeder, `m, β`):** `f` = EFL, `f1 = f/m` = primary focal length,
`R1 = 2·f1` (concave primary, R>0), `β` = (primary-vertex→focus)/`f1`.
Cassegrain-family secondary is **convex** (`R2 > 0`); Gregorian secondary is **concave**
(`R2 < 0`). All lengths in metres. Conics dimensionless.

**How to use:** build each geometry from its inputs, run the MACOS trace, and assert the
emitted `R1, R2, K1, K2` match the table (and that on-axis spherical aberration is null
for every row except — by design — the Dall–Kirkham off-axis coma and the Gregorian).
The `spherical residual` column is the master-condition check `1+K1 − (k⁴/p³)[K2 +
((m+1)/(m−1))²]`; it is machine-zero where the design is spherical-corrected, which is
itself a unit test of the closed forms.

## Notes per design

- **HST-like RC** — the canary. K1 ≈ −1.0023 and K2 ≈ −1.499 are the published HST
  conics; any β-sign or magnification error moves these visibly. Both mirrors hyperbolic.
- **1 m f/8 Classical Cassegrain** — paraboloid primary (K1 = −1 exactly), hyperboloid
  secondary K2 = −((m+1)/(m−1))² = −(5/3)². Shares R1, R2, sep with the DK row below
  (same first-order layout) so the two are a clean A/B for "conics only" differences.
- **1 m f/8 Dall–Kirkham** — same layout, spherical secondary (K2 = 0), ellipsoidal
  primary. On-axis spherical still nulled; expect large off-axis coma in the trace —
  that *is* the test (DK is a narrow-field design).
- **0.5 m f/15 Cassegrain** — a second classical case at different m, β to catch any
  hard-coded constants.
- **1 m f/12 Gregorian** — paraboloid primary, concave ellipsoid secondary
  (K2 = −((m−1)/(m+1))² = −(3/5)², R2 < 0). Separation > f1 because the secondary sits
  *beyond* prime focus; a real intermediate image forms between the mirrors (natural
  field-stop / Lyot-stop location). Spherical-residual check is marked n/a because the
  concave-secondary sign handling differs from the Cassegrain master form — verify this
  row by tracing rather than by the residual identity.

## First-order layout relations used (Cassegrain branch)

```
f1   = f / m
R1   = 2 * f1
R2   = 2 * f * (1 + beta) / (m^2 - 1)          # convex secondary
sep  = f1 * (m - beta) / (m + 1)               # M1 -> M2
BFD  = beta * f1                               # primary vertex -> focus
k    = (1 + beta) / (m + 1)                    # y2/y1
p    = R2 / R1 = m*(1 + beta) / (m^2 - 1)
```

Gregorian branch: `R2 = -2 f (1+beta)/(m^2-1)`, `sep = f1 (m+beta)/(m-1)`,
`k = (1+beta)/(m-1)`. (Conics from the closed forms in the reference doc.)
