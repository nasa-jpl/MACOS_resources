# `vsg_wip/` — VSG2 planning material (not runnable)

This directory holds **planning material only** for the VSG2 test-arm
optical model: the parameter sketch (`vsg2_params.m`), the layout
figure, the review notes, and the briefing slides.  There is no
runnable template here yet — the built bench lives in
[`../bench_layout/`](../bench_layout), which is the generic form of the
same topology.

Parked under `40_benches/` by the 2026-08 reorganization; Dave may
relocate it to `doc/plans/` (PLAN_EXAMPLES_REORG §Still open).
