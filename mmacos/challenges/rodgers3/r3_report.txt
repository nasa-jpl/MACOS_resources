CONVENTION DECISIONS TAKEN (all engine-truth-verified or gated)

1. LAYOUT: one global frame, metres, beam enters +z; signed CODE V
   thicknesses accumulated directly (m1 +0.664957, stop/m2 -0.057940,
   m3 +0.682888 m).  KrElt = signed CODE V radius (m), KcElt = K
   verbatim, psiElt (0,0,-1)-style (rodgers1 emission precedent).

2. ASPHERES: engine truth read from surfsub.F AsphSrf BEFORE first
   use: AsphCoef(i) multiplies h^(2i+2) of sag along +psiElt
   (fh = sum coef(i)*h^(2i+2); zc = rho - fh*psi).  CODE V ASP
   A,B,C multiply r^4,r^6,r^8 of sag along local +z = -psiElt,
   so AsphCoef = -ASP * (1e9, 1e15, 1e21) [mm->m units].
   Gated by r1 jointly with the geometry.

3. FIELDS: CODE V XAN/YAN tangent-composed,
   dir = [tand(XAN), tand(YAN), 1]/norm.  Gated by r1 (+/-10 deg
   box) and r2-r5 (22 deg offset).

4. SOURCE/PUPIL MODEL: collimated bundle, diameter = EPD 75 mm,
   perpendicular to each field's chief; chief aimed through the
   stop centre (on the m2 plane) by real-ray Newton iteration --
   CODE V aims reference rays at the stop.  The deck carries NO
   ApStop= line ON PURPOSE: the engine keyword triggers
   STRAIGHT-LINE source aiming through StopPos (srcaim.inc), which
   is wrong for a stop that sits after one reflection (it also
   freezes ChfRayPos, discovered as a singular aiming Jacobian).

5. YDE/ADE SIGN MAP -- MEASURED by an 8-configuration screen
   (probe_cfg.m; acceptance = geometry, never WFE-tuning), and it
   REFUTES the NOTES item-3 odd/even reflection-parity rule:
     * ALL YDE VERBATIM (one global frame, no reflection parity,
       stop plane included),
     * ALL ADE sense-flipped uniformly: alpha_macos = -ADE_codev
       in alpha = atan2d(psi_y, -psi_z)
   == exactly the rodgers1 empirical decode (convention_decode.m:
   YDE verbatim, ADE opposite sense, no parity).  Evidence chain:
   (a) the notes map {stop -, rec -YDE/-ADE} misses the SI origin
       by 219.6 mm = 2x recenter YDE (ladder_notesparity_FAIL.log);
   (b) recenter-ADE sign pinned by an origin discriminant
       (flipped sense ~0.0001 mm miss, verbatim ~7.1 mm);
   (c) of 8 {stop, recY, recA} sign sets, TWO are origin-
       admissible; the all-verbatim-YDE one reproduces his map's
       shape (rows 12/22/32 = 2.81/2.56/7.38 waves vs his
       min 1.13 / avg 2.56 / max 8.81) and a physical m3 patch
       (~110-160 mm, inside r5's m3 NRADIUS 326.5); the other
       ({stop flipped}) gives a FLAT map (3.1-4.0 waves) and an
       m3 chief patch at +372 mm -- outside his own m3 aperture.
   Rotations are about the decentered vertex (CODE V: decenter
   first, then tilt).

6. ZERNIKE (r5): engine truth from surfsub.F FreeFormSrf (line
   ~2174): Mon/Zernike sag is applied along +zMon, NOT psi; the
   polynomial (x,y) come from xMon/yMon/lMon.  The deck therefore
   carries the CODE V local surface frame directly (zMon = local
   +z, xMon = +x, yMon = local +y, all tilted with the mirror) and
   the SCO coefficients go in VERBATIM (*1e-3 mm->m), no sign flip.
   ZernType= BornWolf == CODE V standard Zernike TERM-FOR-TERM
   (surfsub.F ZerntoMon2 table: 2 = R cos(theta) x-tilt, 5 = power,
   13 = spherical); macos mode = deck zrn_C_idx - 1 (C1 = NRADIUS
   slot); C2 -> mode 1 = PISTON, real content, CARRIED.
   lMon = NRADIUS*1e-3.  Surface shape data do NOT get the parity
   flip (radii signs do not alternate; neither do ASP/ZRN terms).

7. WFE STATISTIC + REFERENCE: per-field strict RMS WFE = std of
   exact OPL to a reference sphere centred on the spot centroid on
   the frozen deck FPA (Dave 2026-07-31 centroid ruling), anchored
   at the exit pupil (crossing of two aimed chiefs = stop image),
   piston-only removal (design/src strict_refs kernel).  His
   ladder number = ceiling of the 20x20-deg field MAP (dense max),
   NOT the max over the 9 .seq optimization points.

CAVEATS / HONEST LIMITS
* Pupil sampling: uniform circular grid (nGridpts=41, ~1184 rays)
  perpendicular to the chief, diameter 75 mm at every field; CODE V
  grids the STOP uniformly, so our off-axis pupil patch differs by
  the footprint ellipticity (~cos 22 deg in y) and real-ray pupil
  distortion.  r1 footprint check: traced max radius vs paraxial
  stop semi-diameter agree to ~0.2%.
* Object at 1.15e10 mm treated as collimated (focus-shift proxy
  well below the solved image defocus, rodgers1 precedent).
* Map MINIMA on r2 (ours 1889 vs his 1134 nm) and r4 (28.9 vs
  19.9 nm) sit above his; maxima, averages and std track (r1/r3/r5
  moments all within ~10%).  The low end is where the pupil-model
  difference (uniform perpendicular-to-chief bundle vs CODE V's
  stop-gridded rays) and the reference-sphere radius anchor matter
  most relative to the small residual -- a known, bounded
  approximation, NOT a convention error (the gated statistic is
  the map maximum).
* Band rule: PASS = dense-map max within [0.8, 1.25]x of his
  number; the residual ratio is reported, never tuned.
