# macos.design.lens_catalog -- vendor lens prescriptions (fill in your own parts).
#
# Two record types, one per line, fields separated by '|':
#
#   part  | <part> | <vendor> | <R1;R2;...> | <t1;t2;...> | <glass1;glass2;...> | <D> | <EFL> | <BFL> | <lambda_nm> | <source>
#   glass | <name> | <B1 B2 B3 C1 C2 C3> | <nd> | <source>
#
# Units mm and nm.  Radii in the CODE V sign convention (light travels from
# R1 toward the last surface; a radius is positive when its centre lies
# downstream), Inf for plano.  A cemented interface is ONE radius (a vendor
# table that lists R2 and R3 separately for a cemented pair lists the same
# number twice: enter it once).  t(k) is the centre thickness from surface k
# to k+1; glass(k) the medium between them ('air' for an air-spaced pair).
# EFL, BFL and lambda_nm are the vendor's quoted values: macos.design.lens_catalog
# returns them beside the Lens and the tests check the paraxial solve against them.
#
# A glass the engine table (macos_f90/macos_glass_list.txt) does not carry is
# given here as its Sellmeier row (n^2 - 1 = sum B_i L2/(L2 - C_i), L2 in um^2);
# nd is the published index at 587.56 nm, the check the loader's test applies.
# The deck carries the row as GlassCoef=, so the engine traces it exactly.
# Lines starting with '#' are comments.
