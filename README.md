# MACOS_resources
MACOS is "Modeling and Analysis for Controlled Optical Systems"

MACOS was created at the Jet Propulsion Laboratory

This repository contains:

Generic MACOS Interface (GMI): uses MATLAB as a front end for specific analyses.

pymacos: uses python as a front end, and provides linear model generation and wide-ranging test facilities.

mmacos: uses Matlab as a front end, and provides linear model generation and optical design layers. More versatile than GMI.
